&nbsp;&nbsp;&nbsp;&nbsp;Edmond Locard said that it is impossible for a criminal to act without leaving traces of this presence, especially considering the intensity of a crime.

&nbsp;&nbsp;&nbsp;&nbsp;This principle signifies that an action results in evidence, and it works in not only physical but also digital worlds.

| | <center> Examples of Traces</center> |
| :-: | :-- |
| Physical World | Blood trail, footprint, fingerprint |
| Digital World | Windows registry, malware signature, network traffic|
